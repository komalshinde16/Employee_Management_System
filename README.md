# Employee Management System

This is a simple Java console application to manage employee details.

## Features
- Add new employee
- View all employees
- Search employee by department
- Update employee details
- Delete employee record
- Generate salary report
- Save data to file
- Load data from file

## Concepts Used
- Java OOP
- ArrayList and HashMap
- File Handling (Serialization)
- Exception Handling
- MVC structure

## How to Run
1. Open project in IntelliJ 
2. Run `Main.java`
3. Follow menu options in console

## Note
Enter salary in numbers only (example: 25000)
